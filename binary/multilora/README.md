## 架构特点

- **Multi-LoRA 违规召回率普遍更高** — 对违规信号更敏感
- **Full FT clean 召回率更高** — 对安全内容判断更准确
- **Multi-LoRA 适配器仅 2MB** — 适合多国部署
- **独立 Full FT 需要 1.1GB/国** — 适合对精度要求最高的场景
